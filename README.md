# Polyglot AI 🦜

A single-file, offline-first language-learning app. Everything — lessons,
activities, review, settings — lives in one HTML file: no server, no build
step, no account, no tracking.

**Try it:** open the published app above (GitHub Pages) or download
`index.html` and open it in any modern browser. Chrome or Edge are
recommended (they add speech recognition); Safari and Firefox provide
voices.

## What's inside

- 36 languages — 4 fully verified (Español, Français, Deutsch, 日本語),
  32 machine-validated drafts (clearly marked)
- Immersion lessons (15 per language), scenarios, stories, listening,
  reading, speaking, vocabulary, numbers and ear training
- Spaced-repetition review with a 6-state knowledge model
- Interface in 10 languages, including right-to-left Arabic
- Optional Supabase account sync — **off by default**: the app is 100%
  usable offline and without an account

The whole app is `index.html` on the `main` branch, served by GitHub Pages.
